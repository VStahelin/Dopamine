# 0007. Desenvolver a run primeiro, depois o resto

- **Status:** proposta
- **Data:** 2026-10-21
- **Área:** processo

## Contexto

O jogo tem muitos sistemas (run, idle, organismo, economia, reset). O [conceito](../conceito.md) sugere começar por um protótipo jogável só do campo crônico.

## Decisão

O desenvolvimento segue o [roadmap](../roadmap.md): fundação, protótipo da run, profundidade da run, meta-progressão, idle, organismo e polimento. Cada fase tem um critério de saída que precisa ser cumprido antes da próxima.

## Alternativas consideradas

- **Construir todos os sistemas em paralelo:** só dá para saber se o jogo é divertido no fim.
- **Começar pelo idle:** mais simples, mas não testa o coração do jogo.

## Consequências

- Idle, organismo e economia esperam a run estar divertida.
- Mudanças de ordem ou de escopo de fase viram decisões novas.
