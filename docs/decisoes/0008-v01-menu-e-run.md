# 0008. A primeira versão (v0.1) tem menu e uma run jogável

- **Status:** proposta
- **Data:** 2026-10-21
- **Área:** processo

## Contexto

A fase 1 do [roadmap](../roadmap.md) era só um protótipo da run. O Vitor quer que a primeira versão já seja um jogo de ponta a ponta: um menu com algumas opções e uma run que dá para jogar.

## Decisão

A fase 1 passa a se chamar "Primeira versão jogável (v0.1)" e entrega o ciclo completo menu → run → fim → menu. O menu tem tela de título, Jogar, Recordes e Opções; a run tem pausa e tela de fim com recordes. Um save mínimo guarda recordes e opções.

## Alternativas consideradas

- **Só a run, sem menu:** mais rápido, mas não parece um jogo para mostrar a ninguém.
- **Menu com meta-progressão (loja de upgrades, escolha de agente):** depende de moeda, economia e de mais de um agente, que estão nas fases 2 e 3.

## Consequências

- A fase 1 fica um pouco maior.
- O save começa já na fase 1, só com recordes e opções; a fase 3 estende o mesmo formato com moeda e upgrades.
- O menu da v0.1 é a base onde a loja (fase 3) e a escolha de agente (fase 2) entram depois.
